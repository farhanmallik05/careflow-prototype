    session_cookie_secure: bool
    trusted_origins: tuple[str, ...]

    oidc_client_id: str | None
    oidc_client_secret: SecretStr | None

    oidc_role_claim: str | None
    message_provider: Literal["rule_based", "llm"]

    @classmethod
    def for_demo(...): ...
    @classmethod
    def from_environment(...): ...
    def validate_for_runtime(self) -> None: ...

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Process environment/secret manager → `Settings` | Untrusted or misconfigured deployment values control security and data-path behavior. |
| `Settings` → FastAPI bootstrap/routes | Configuration decisions determine whether protected/demo functionality is registered and served. |
| Runtime diagnostics → operator/probe | Safe status crosses an unauthenticated boundary and must not disclose secrets, paths, claims, or case data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-05 | Elevation of privilege | Pilot demo-login/ID-login routes | mitigate | Gate both routes on `Settings.mode == "demo"`; diagnostics-only bootstrap exposes neither as a working authentication path. |
| T-01-06 | Tampering | Pilot settings and trusted origins | mitigate | Validate enum values, secure-cookie requirement, exact HTTPS origins, redirect-origin membership, required OIDC fields, and high-entropy non-placeholder secrets before protected serving. |
| T-01-07 | Information disclosure | `/health/ready` and startup diagnostics | mitigate | Return allowlisted fields and reason codes only; redact `SecretStr`, URLs/paths, claims, patient content, cookies, and message/outbox values. |
| T-01-08 | Denial of service | Unsafe/missing data path | mitigate | Reject `:memory:`, relative/demo/package paths, missing/unwritable parents, and contradictory pilot values before opening the store; retain liveness for process supervision. |
| T-01-09 | Spoofing | Environment alias/duplicate configuration | mitigate | Use one canonical `CAREFLOW_*` Settings source, reject invalid modes/values, and do not let `.env` or legacy names silently override deployment configuration. |
</threat_model>
