<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Git checkout -> build context | Tracked and untracked files become potential image inputs; secrets, local SQLite data, caches, and host paths must not cross this boundary. |
| Dependency/image registries -> Docker build | Mutable tags or unverified dependency resolution can change the runtime without a source change. |
| Container process -> `/data` volume | The service needs writable SQLite state, but the runtime must not require root and must not receive secrets from the image. |
| Operator shell/environment -> application | Session configuration crosses through environment variables; the repository may contain names and placeholders only, never secret values. |
